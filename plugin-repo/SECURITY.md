# Security

Continuum runs on your machine: it records into `.continuum/` in each repository and serves its dashboard on 127.0.0.1 only. Reports about anything that could expose that data, or let another process or site read or change it, are welcome.

**Report a vulnerability privately** through [GitHub's private vulnerability reporting](https://github.com/PranavOaR/continuum-plugin/security/advisories/new), never in a public issue. Include the Continuum version (`npx getcontinuum --version`), what an attacker needs, and steps to reproduce.

You will get a reply within a week. Fixes ship in the next release, and the CHANGELOG credits you if you want.
